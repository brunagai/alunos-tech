# Resumo

O presente trabalho desenvolve a Plataforma de Gestão de Cursos e Suporte Corporativo da Alunos Tech, empresa fictícia de serviços corporativos digitais. O objetivo geral foi integrar capacitação e suporte com nuvem e DevOps, gestão ágil, programação .NET e programação de banco de dados. A solução entrega uma API .NET 8, o portal web do gestor, a página de navegador do colaborador e o aplicativo .NET MAUI. O aplicativo compilou para Windows e para Android. No emulador, a matrícula do colaborador contra o cluster local respondeu HTTP 201. O PostgreSQL guarda aluno, curso, matrícula e chamado, com índice único, procedimento, função, gatilho e papel sem permissão de exclusão. O Compose continua só com o banco. O cluster kind recebeu a API e o PostgreSQL interno. As sondas /health/live e /health/ready responderam Healthy, o metrics-server expôs CPU e memória, e o HPA chegou a seis réplicas. A imagem foi publicada no registro local localhost:5001 e o rollout concluiu. O build que pedia as imagens oficiais 8.0.427 e 8.0.33 falhou com EOF do daemon; a imagem executada usou aspnet:10.0 com roll-forward. Registro público, nuvem de provedor, loja e desktop permanecem evolução.

**Palavras-chave:** Arquitetura de software. .NET. PostgreSQL. Docker. Teste de software.

# Abstract

This work develops the Course Management and Corporate Support Platform for Alunos Tech, a fictional digital corporate services company. The general objective was to integrate training and support with cloud and DevOps practices, agile management, .NET programming, and database programming. The solution delivers a .NET 8 API, the manager web portal, the employee browser page, and the .NET MAUI application. The application compiled for Windows and Android. On the emulator, the employee enrollment against the local cluster returned HTTP 201. PostgreSQL stores the employee, the course, the enrollment, and the ticket, with a unique index, a procedure, a function, a trigger, and a role that cannot delete rows. Compose still runs only the database. The kind cluster received the API and the internal PostgreSQL. The /health/live and /health/ready probes returned Healthy, metrics-server exposed CPU and memory, and the HPA reached six replicas. The image was published to the local registry localhost:5001 and the rollout completed. The build that requested the official 8.0.427 and 8.0.33 images failed with a daemon EOF; the image that ran used aspnet:10.0 with roll-forward. A public registry, a provider cloud, an app store, and the desktop module remain future work.

**Keywords:** Software architecture. .NET. PostgreSQL. Docker. Software testing.
